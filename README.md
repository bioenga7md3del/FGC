# FGC System

نظام ويب لإدارة العقود والميزانيات والتعميدات والمستخلصات وإجازات الموظفين ومعايرة الأجهزة. مبني على HTML/JS ويستخدم Firebase (Auth + Firestore).

## هيكل المشروع

```
index.html                 تسجيل الدخول / إنشاء حساب
dashboard.html             لوحة تحكم المدير (العقود، المواقع، المستخدمين، النسخ الاحتياطي)
contract-details.html      تقرير عقد
details_finance.html       مالية الموقع (التعميدات)
details_vacations.html     إجازات موظفي الموقع
details_subcontracts.html  المستخلص الشهري (عمالة، زيارات، حسميات)
subcontracts_config.html   القوائم الثابتة للمستخلص
details_calibration.html   أجهزة القياس والمعايرة
vacations.html             الإجازات المركزية + حل تعارضات البدلاء
calendar.html              الخط الزمني للإجازات
css/app.css                ملف التصميم الموحد
js/core.js                 إعدادات Firebase + الحماية + أدوات مشتركة
firestore.rules            قواعد الأمان لقاعدة البيانات
```

## الصلاحيات

| الصلاحية | يرى | يعدّل | يرى الأرباح |
|---|---|---|---|
| `admin` | كل المواقع | نعم | نعم |
| `user` | موقعه فقط | نعم | لا |
| `viewer` | موقعه فقط | لا | لا |
| `viewer_pro` | موقعه فقط | لا | نعم |

أي حساب جديد يُنشأ بصلاحية `user` بدون موقع، ويظل "بانتظار التفعيل" لحد ما المدير يحدد له موقع من شاشة المستخدمين.

## ⚠️ خطوة إلزامية: تفعيل قواعد الأمان

الواجهة بتخفي الأزرار حسب الصلاحية، لكن **الحماية الحقيقية لازم تكون في Firestore Rules**:

1. افتح [Firebase Console](https://console.firebase.google.com/) ← مشروع `fgcbio` ← **Firestore Database** ← **Rules**.
2. انسخ محتوى ملف `firestore.rules` كله والصقه مكان الموجود.
3. اضغط **Publish**.

> قبل النشر اتأكد إن حسابك في مجموعة `users` عنده `role: "admin"`، عشان متقفلش على نفسك.

## ملاحظات

- عمليات الاستيراد والحذف الجماعي بتتقسم على دفعات (حد Firestore 500 عملية للدفعة).
- النسخة الاحتياطية (من لوحة التحكم) بتشمل كل المجموعات، والاستعادة بتضيف/تحدّث بدون حذف.
- الأرقام تُعرض بالأرقام الإنجليزية لسهولة التصدير لـ Excel.
